# 网页工具箱（Webhook + 随机滚动）

全站网页工具箱：任意页面注入悬浮工具箱按钮，展开功能宫格，内置 Webhook 触发与随机滚动两个工具。

## 功能

- **悬浮工具箱启动器** — 页面角落显示圆形 🛠 按钮（位置、偏移可配置），点击展开 2×2 功能宫格
- **Webhook 触发** — 宫格内查看匹配当前页面的触发器，一键发送请求，实时显示 已触发 / 失败 / 超时 / 网络错误
- **随机滚动** — 距离、时长、停顿全部随机，模拟真人阅读式滚动，参数可视化调整
- **Webhook 设置** — 管理按钮与请求：多按钮、匹配 URL、Font Awesome 图标、文字、颜色、默认 / GitHub 两种 Webhook 类型、测试请求

## 使用方式

1. 安装脚本，打开任意网页（`@match *://*/*`，全站运行）
2. 页面角落出现蓝色圆形悬浮按钮 🛠，点击展开功能宫格
3. 选择功能：
   - **Webhook 触发** — 列出匹配当前页面的按钮，点击即发送
   - **随机滚动** — 打开滚动面板，开始 / 停止 / 调整参数
   - **Webhook 设置** — 添加 / 编辑 / 删除 / 测试 Webhook 按钮

Webhook 配置方式与 [Webhook 触发](../webhook/README.md) 脚本完全一致，含 GitHub 类型（Token + 仓库名 + 事件名自动生成请求）和 Token 创建步骤，详见该文档。

> 网页工具箱整合了 Webhook 触发脚本的全部能力，两者同时安装会在页面上重复注入按钮，建议只安装其一。

## 随机滚动

每次滚动的距离、时长、停顿都在配置区间内随机取值，并按概率插入长停顿，行为更接近真人阅读。

### 底部确认（防误判）

下拉加载（无限滚动）的页面加载慢时，刚滚到底新内容还没撑高页面，会被误判为已到底。脚本在判定到底后会先做若干次重试：等待 → 检查页面是否变高 → 轻微上移再滚回底部触发懒加载监听。只有全部重试都没有加载出新内容，才执行「到底后」的动作（停止或回顶部）；中途加载出新内容则继续正常滚动。重试次数和等待时长见上表。

### 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 最小 / 最大滚动距离 | 220 / 500 px | 单次滚动像素区间 |
| 最短 / 最长滚动时间 | 250 / 600 ms | 单次滚动动画时长区间（缓动） |
| 最短 / 最长普通停顿 | 150 / 500 ms | 两次滚动之间的停顿区间 |
| 长停顿概率 | 8 % | 停顿时触发长停顿的概率 |
| 最短 / 最长长停顿 | 1500 / 3500 ms | 长停顿时长区间 |
| 到底后 | 停止 | 到底行为：`停止` 或 `回顶部继续`（回顶后停 1.5s 再滚） |
| 底部判断距离 | 5 px | 距页面底部多少像素视为到底 |
| 底部确认重试次数 | 3 次 | 到底后重试探测的次数，防止下拉加载慢导致误判（0 为关闭） |
| 底部重试等待 | 800 ms | 每次底部重试前等待新内容加载的时长 |
| 页面加载后自动开始 | 关 | 开启后每个页面加载即自动滚动 |

### 面板按钮

- **开始 / 停止** — 启动或中断滚动循环
- **应用并保存** — 保存当前面板参数
- **恢复默认** — 重置为上表默认值

配置通过 `GM_setValue` 持久化，并以 `localStorage` 双写备份，保存在本浏览器。
